🎯 CE ESTE ACEASTĂ APLICAȚIE?

Convertește coordonate Stereo 70 (sistemul românesc) în GPS și
te ghidează acolo cu Google Maps.

Ideal pentru: topografi, ingineri, arhitecți, specialiști cadastru.

🚀 START SUPER RAPID (3 PAȘI):

Pasul 1: Instalează Android Studio
         → https://developer.android.com/studio
         → Download → Instalează → Configurare automată

Pasul 2: Deschide Proiectul
         → Android Studio → Open
         → Selectează folderul "Stereo70Navigator"
         → Așteaptă Gradle Sync (3-5 min)

Pasul 3: Compilează APK
         → Build → Build Bundle(s) / APK(s) → Build APK(s)
         → Găsește APK în: app\build\outputs\apk\debug\

Gata! Acum copiază app-debug.apk pe telefon și instalează!

📱 CUM FOLOSESC APLICAȚIA?

După ce ai instalat-o pe telefon:

1. Introduci coordonate Stereo 70:
   X: 500119
   Y: 357429

2. Apeși "Convertește" → vezi GPS-ul

3. Apeși "Navighează" → se deschide Google Maps!

4. Poți salva la Favorite pentru mai târziu

5. Poți importa sute de coordonate dintr-un fișier CSV

🔧 CERINȚE:

Pentru Dezvoltare (PC):
  - Windows 10/11, macOS sau Linux
  - RAM: 8 GB minim (16 GB recomandat)
  - Spațiu: 10 GB liber
  - Internet pentru download-uri

Pentru Aplicație (Telefon):
  - Android 7.0 sau mai nou
  - Google Maps instalat (opțional, folosește browser-ul altfel)
  - 10 MB spațiu liber

💡 PROBLEME FRECVENTE:

P: "Gradle sync failed"
R: File → Invalidate Caches / Restart

P: "SDK not found"
R: Tools → SDK Manager → Instalează Android 14.0

P: APK nu se instalează pe telefon
R: Setări → Securitate → Activează "Surse necunoscute"

P: Aplicația crashes
R: Verifică că ai Android 7.0 sau mai nou

Pentru mai multe soluții: GHID_INSTALARE.md → Rezolvare Probleme
