┌───────────────────────────────────────────────────────────────────────────┐
│  METODA 1: GITHUB ACTIONS (ZERO INSTALĂRI) ⭐ RECOMANDAT                 │
│  Timp: 5-10 minute | Dificultate: ★☆☆☆☆                                  │
└───────────────────────────────────────────────────────────────────────────┘

  🎯 Pași:

  1. Creează cont GitHub (gratuit):
     → https://github.com
     → Sign up → Verifică email

  2. Creează repository:
     → Click "+" → "New repository"
     → Nume: Stereo70Navigator
     → Create repository

  3. Upload fișiere:
     → "Add file" → "Upload files"
     → Selectează TOT din folderul Stereo70Navigator
     → Trage și plasează fișierele
     → "Commit changes"

  4. Rulează build:
     → Click tab "Actions"
     → Click "Build Android APK"
     → "Run workflow" → Așteaptă 3-5 min

  5. Descarcă APK:
     → Click pe run-ul ✅ verde
     → Scroll jos la "Artifacts"
     → Click "app-debug" → descarcă ZIP
     → Dezarhivează → găsești app-debug.apk

  6. Instalează pe telefon!
     → Copiază APK pe telefon (email/Drive/USB)
     → Deschide și instalează

  📖 Ghid detaliat: GITHUB_BUILD.md

═══════════════════════════════════════════════════════════════════════════

┌───────────────────────────────────────────────────────────────────────────┐
│  METODA 2: ANDROID STUDIO (INSTALARE NECESARĂ)                           │
│  Timp: 40 minute prima dată, apoi 3 min | Dificultate: ★★☆☆☆             │
└───────────────────────────────────────────────────────────────────────────┘

  🎯 Pași:

  1. Instalează Android Studio:
     → https://developer.android.com/studio
     → Download → Instalează (30 min)

  2. Deschide proiectul:
     → Android Studio → Open
     → Selectează folderul Stereo70Navigator
     → Așteaptă Gradle Sync (3-5 min)

  3. Compilează APK:
     → Build → Build Bundle(s) / APK(s) → Build APK(s)
     → Așteaptă 2-4 min

  4. Găsește APK:
     → Click "locate" în notificare
     → SAU: app\build\outputs\apk\debug\app-debug.apk

  5. Instalează pe telefon!
     → Copiază APK pe telefon
     → Deschide și instalează

  📖 Ghid rapid: COMPILARE_SIMPLA.md
  📖 Ghid detaliat: START_AICI.md

│  🤔 CARE METODĂ SĂ ALEG?                                                  │
└───────────────────────────────────────────────────────────────────────────┘

  ✅ ALEGE GITHUB ACTIONS DACĂ:
     • Nu vrei să instalezi nimic pe PC
     • Vrei APK rapid, fără complicații
     • PC-ul tău e slab (puțin RAM/spațiu)
     • Prima dată când compilezi Android

  ✅ ALEGE ANDROID STUDIO DACĂ:
     • Vrei să modifici codul frecvent
     • Ai PC puternic (8GB+ RAM, 10GB+ spațiu)
     • Vrei control total și debugging
     • Ești developer sau vrei să înveți
